# Kilo

A small text editor written in C, built by following the
"Build Your Own Text Editor" booklet.

## About

This project is based on antirez's kilo. I'm following the booklet
step by step to learn C and how terminals work.

## Build and run

    make
    ./kilo

Press q to quit.
